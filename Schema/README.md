## Adding an Update

Keep the existing file unchanged. Add each new SEO team delivery as a new file using this format:

`Hilston-Park-[scope]-Schema-v[number]-YYYY-MM-DD.csv`

Add a row above with its version number, date, filename, and scope. Commit the source file and this register together so GitHub retains the full version history.
